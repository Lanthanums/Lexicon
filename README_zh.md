# Lexicon

**让每一个词，各得其所。** 一款 Windows 桌面词汇学习应用，用于收藏单词、整理词汇关系和练习回忆。

[English](README.md) · [下载](https://github.com/Lanthanums/Lexicon/releases) · [更新记录](RELEASE_NOTES.md)

当前源码版本为 **v2.0 beta2**（`2.0.0-beta.2`）。界面为中文，支持浅色、深色和跟随系统。Release 下载包与 `main` 分支源码的版本可能不同，下载时请查看对应版本标题。

## 你的词汇空间

| 功能分块 | 可以做什么 |
| --- | --- |
| 今日学习 | 查看每日一词、日历与近 14/30 天的实际学习足迹，开始今天的复习。 |
| 录入与管理词汇 | 查询释义、批量录入，整理形近组、近义组、自定义组，也可保留独立单词。 |
| 综合抽查 | 进行选择、拼写、渐进提示和近义回忆练习，结束后巩固错题。 |
| 设置与备份 | 调整外观、词典和近义匹配偏好，导出、导入或恢复本地词库。 |

## 开始使用

从 [Releases](https://github.com/Lanthanums/Lexicon/releases) 下载所需版本的 Windows 程序。可以运行安装包，或完整解压便携包后，在应用目录中运行 `Lexicon.exe`。启动前先退出旧版；如果 Release 中尚无 beta2 程序，可按下方说明从源码构建。

1. 打开「录入与管理词汇」，输入单词。批量录入用分号分隔，例如 `effluent;affluent;effulgent`，也支持中文分号和换行。
2. 在同一个确认窗口中补充缺失释义、选择有歧义的归组，再保存整批词汇。取消会保留输入，不会入库。
3. 整理词库后，打开「综合抽查」练习；需要可迁移的词库副本时，从「设置与备份」导出 JSON。

首次教学会介绍四个功能分块，并提供四项容易错过的操作练习。练习使用真实管理界面和临时示例词库，退出后丢弃。可以跳过任一练习、按 Esc 退出，之后也可从设置重新打开。

## 整理单词与关系

蓝色卡片是形近组，绿色是近义组，灰色是自定义组，黄色是独立单词。每个词可同时拥有每种关系各一个；没有任何关系时，才显示为独立单词。自动匹配结果可以手动调整，近义关系是否适用于具体表达仍需结合语境判断。

卡片展示单词、音标、可展开的一行释义和五点熟练度。右上角铅笔进入统一编辑器，管理组名、笔记、类型、成员、顺序和词条详情；展开成员后可以编辑释义、音标、用法与例句。列表视图中每个词只显示一次，保留归属标签和排序功能。

| 不太显眼的操作 | 效果 |
| --- | --- |
| 把单词拖到另一张卡片 | 只移动这个成员，加入目标关系。 |
| 从卡片的非单词区域拖动 | 合并整张卡片；同类型沿用原类型，不同类型默认成为自定义组，并保留明确选择类型的入口。 |
| 在编辑器中长按三横线手柄，再拖动 | 调整成员顺序；也可以聚焦手柄，用上下方向键排序。 |
| 点击编辑器中的五个熟练度点 | 打开 0–5 滑条，保存编辑后生效；手动调整不会增加答题次数。 |

移动成员会保留它的其他类型关系。尚未确认的合并类型在重启后仍可选择，直到你明确决定；撤销可恢复先前的成员与顺序。

编辑器区分「移出本组」「全局删除单词」和「解散分组」。移出、解散会保留单词与学习记录；删除单词会清除它的全部关系和记录；解散还会移除该组笔记。相关操作有确认和撤销，关闭有未保存修改的编辑器时会询问是否放弃。

## 练习与复习

抽查优先安排到期词，其次是未学词，之后才是提前练习。间隔会根据距离上次复习的时间、回忆结果和错误调整；答错后约五分钟再次安排，立刻连续刷对不会无限拉长间隔。

拼写提示依次给出首字母、音标和完整单词，提示辅助的回答不提升熟练度。近义回忆不要求顺序：最多三个成员时需全对，更多成员需至少答对 80%（向上取整）。即使组题通过，遗漏成员仍可巩固。错题队列在追加练习轮次间保留，完成重练或重置后清除。

调度采用透明的启发式指数模型，并非训练后的 FSRS，也不提供经过校准的个人记忆保持率。七天图表是假设按计划复习且全部答对、不新增词的情景推演。具体规则和边界见 [记忆调度说明](MEMORY_SCHEDULING.md)。

## 本地数据、词典与备份

词库保存在本机，支持桌面自动快照和 JSON 导出、导入。导入需要确认，并保留导入前的恢复副本；没有云同步。空白分发包不包含个人学习记录，但普通启动仍会读取本机已有词库。

- 试用 beta 或切换版本前，请先导出备份。v2 新增自定义组、成员顺序和未决合并类型，旧版不能完整理解这些字段。已有单词 ID、释义和学习记录保留；历史冲突近义关系仍可从 `relationArchive` 导出。
- 词典和近义服务凭据保存在本机，可能包含在导出的备份里，分享备份前请先检查。
- 离线近义候选使用随包的 **Open English WordNet 2025** 索引。可选 API 校验使用 Datamuse；查义使用所配置的词典服务，这些请求需要联网。应用没有安装或训练端侧模型。
- 公共词典数据与个人词库分开。数据和依赖的许可、署名见 [第三方声明](THIRD_PARTY_NOTICES.md)。

## 构建与运行

使用 Node.js 22.12+ 或 24 和 npm，打包目标为 Windows。

```sh
git clone https://github.com/Lanthanums/Lexicon.git
cd Lexicon
npm ci
npm run setup:electron
npm run build
npm run desktop
```

浏览器界面开发可运行 `npm run dev`；桌面快照和系统外观集成需要在 Electron 中使用。

```sh
# Windows 应用目录
npm run desktop:pack

# Windows 安装包
npm run desktop:dist
```

构建产物位于 `release/`。源码仓库不包含个人配置、API 凭据或已安装的依赖目录。
