# 词库拖拽分组规则

在目标卡片上停留时，从左到右始终是「形近组」「近义组」「自定义组」。鼠标所在分区扩到一半宽度。松手按高亮分区执行，推荐只提供线索。卡片上只显示三个分区，不叠加文字说明。长卡片上的分区图标和文字会随可见区域移动。拖拽时靠近窗口上下缘，页面会缓慢滚动。列表以每一行的单词为目标，使用相同的分区。

## 整组卡片和独立单词

拖卡片标题或留白会带上整组。合并时按选中的类型保存。如果目标就是该类型，沿用目标组。否则，来源是该类型的整组时沿用来源组；其余情况新建。合并只处理参与拖放的两张卡片，其他关系遵循下文的保护规则。

| 来源 → 目标 | 选形近组 | 选近义组 | 选自定义组 |
| --- | --- | --- | --- |
| 形近组 → 形近组 | 合入目标 | 两组替换为近义组 | 两组替换为自定义组 |
| 形近组 → 近义组 | 合入来源形近组 | 合入目标近义组 | 两组替换为自定义组 |
| 形近组 → 独立词 | 独立词加入来源组 | 整组与独立词成近义组，替换来源组 | 整组与独立词成自定义组，替换来源组 |
| 近义组 → 形近组 | 合入目标形近组 | 合入来源近义组 | 两组替换为自定义组 |
| 近义组 → 近义组 | 两组替换为形近组 | 合入目标 | 两组替换为自定义组 |
| 近义组 → 独立词 | 整组与独立词成形近组，替换来源组 | 独立词加入来源组 | 整组与独立词成自定义组，替换来源组 |
| 独立词 → 形近组 | 加入目标 | 与目标组成员另建近义组 | 与目标组成员另建自定义组 |
| 独立词 → 近义组 | 与目标组成员另建形近组 | 加入目标 | 与目标组成员另建自定义组 |
| 独立词 → 独立词 | 两词新建形近组 | 两词新建近义组 | 两词新建自定义组 |

自定义组卡同样按整组规则处理。「另建」表示原卡保留，相关词条仍共享释义和学习记录。

## 只拖组内一个词

| 来源 → 目标 | 选形近组 | 选近义组 | 选自定义组 |
| --- | --- | --- | --- |
| 形近组的词 → 形近组 | 转到目标形近组 | 与目标成员另建近义组 | 与目标成员另建自定义组 |
| 形近组的词 → 近义组 | 与目标成员另建形近组 | 加入目标近义组 | 与目标成员另建自定义组 |
| 形近组的词 → 独立词 | 两词新建形近组 | 两词新建近义组 | 两词新建自定义组 |
| 近义组的词 → 形近组 | 加入目标形近组 | 与目标成员另建近义组 | 与目标成员另建自定义组 |
| 近义组的词 → 近义组 | 与目标成员另建形近组 | 加入目标近义组 | 与目标成员另建自定义组 |
| 近义组的词 → 独立词 | 两词新建形近组 | 两词新建近义组 | 两词新建自定义组 |

每个词可以同时属于多个近义组，各属于至多一个形近组和自定义组。单词落到形近或自定义分区时，如果它已有该类分组，只转移被拖的词，预览会说明。只剩一个成员的组按现有词库规则处理。

如果**整组合并**或**借用目标组成员另建**会把成员移出未参与的形近组或自定义组，该分区显示禁止图标，松手不执行并以通知说明原因。重复加入另一张卡片里的组或产生完全相同的组也同样处理。在来源卡片上松手会直接取消，清除遮罩。拖组内单词到卡片外仍只解除来源关系。同一次成功拖放可通过通知撤销。

以前等待选型的自定义组会以自定义组继续显示，可以通过铅笔改类型。
