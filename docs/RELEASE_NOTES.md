# Lexicon v3.0

## 中文

Lexicon 是一款 Windows x64 本地词汇应用，支持深色、浅色和跟随系统。

- **录入与管理** — 分号或多行粘贴，每批查询最多 100 词。重复词会跳过，缺失释义和归组歧义可以集中确认。形近组、近义组和自定义组可同时存在，支持卡片、分页列表、搜索、拖动和撤销。
- **词汇关系** — 离线近义建议使用 Open English WordNet 2025，包括直接相连的形容词义项。手动组在自动重新分组时保留原成员、顺序和笔记。解散的命名关系可在归档里查阅。
- **综合抽查** — 六种考查方式，按到期优先安排复习，提供掌握构成和七天趋势。词库工具栏滚动时置顶，背景带渐隐模糊。
- **本地资料** — JSON 导入、导出、每日快照和导入前恢复。桌面端可在浏览器存储不足时使用磁盘快照。覆盖安装可继续使用本机资料。

附件提供 Windows x64 安装包、便携包、源码包、发布清单和 SHA-256 校验文件。便携包完整解压后运行 Lexicon.exe。安装包尚未签名。

## English

Lexicon is a local Windows x64 vocabulary app with light, dark and system appearance modes.

- **Entry and management** — Paste semicolon-separated words or separate lines, up to 100 lookups per batch. Review missing definitions and ambiguous grouping choices together. Spelling, synonym and custom relationships can coexist. Use paginated cards or lists, search, drag and undo.
- **Word relationships** — Offline suggestions use Open English WordNet 2025, including direct adjective sense links. Automatic regrouping preserves curated members, order and notes. Dissolved named groups are available in the relation archive.
- **Review** — Six quiz modes, due-first review, a mastery breakdown and a seven-day forecast. The management toolbar stays visible over a softly blurred background as you scroll.
- **Local library** — JSON import and export, daily snapshots and pre-import recovery. Desktop snapshots can use disk storage when browser storage fills up. An in-place upgrade opens the existing local library.

Downloads include a Windows x64 installer, portable archive, source archive, release manifest and SHA-256 checksums. Extract the entire portable archive before running Lexicon.exe. The installer is unsigned.
